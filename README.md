This is a LaTeX class for a thesis at the _Institute for Atmospheric and Environmental Sciences, Goethe University Frankfurt, Germany_.

Make sure that the `IAUthesis.cls` is in the same folder as the LaTeX file containing your thesis.

Please refer to the `IAUthesis_documentation_example.pdf` to learn about the _options_ this class provides.

The `template.tex` can be used to start a new document.

If you encounter a bug or whish for a feature, please open an _issue_.
